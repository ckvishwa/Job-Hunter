# R6.5 Ownership and conventions

`.github/CODEOWNERS`: owner on `/` (existing), and explicitly on `/src/candidate/`, `/src/application/`, `/docs/aim/`, `/docs/DECISIONS.md`. `.github/pull_request_template.md` now asks for the AIM and task ID, gates run with counts, the privacy check result, an ADR link when scope, architecture, a contract, privacy or storage changed, live gates still pending, and the commit convention `type(scope): summary` with the task ID in the body. The draft PR for R7.3 shows the template.
